# 09 – Código fuente en repositorio Git

Todo el código fuente del sistema se mantiene en las carpetas **`backend`** y **`frontend`**, que permanecen en la raíz del repositorio:

- **`backend/`** — API REST (Node.js + Express), modelos de Mongo, servicios de procesamiento con IA (OpenRouter), búsqueda semántica (Atlas Vector Search) y scripts de utilidad del servidor.
- **`frontend/`** — Aplicación web (React + Vite) con el panel tipo SaaS (Dashboard, Repositorios, Documentos y Búsqueda Inteligente).

El repositorio Git completo está publicado en:
https://github.com/pintoplataemmanuel-stack/Sistema_Documental_IA
